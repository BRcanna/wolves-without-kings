# Bulgaria Underworld Game — Mechanics Engineering Docuseries

This is the expanded multi-document version of the game concept. It is intentionally structured like a repository rather than a single design document.

The target game is a Bulgaria-centered European organized-crime RPG with more agency than a conventional GTA-like open world, long-horizon Red Dead-style lived character development, Cyberpunk-2020-like role freedom, District-B13-inspired physical traversal, CONDITION-derived hidden competence/familiarity/persistence, and both a complete single-player campaign and a persistent social/online underworld.

## Core product statement

**The player is not leveling a crime avatar. The player is living a criminal life in a world that keeps history.**

Days create habits. Months create competence. Years create identity. Objects, people, organizations, places, police cases and markets remember enough history for those years to matter.
