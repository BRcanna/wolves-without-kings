# Section 41 — Qualitative UI/UX projection

This episode composes the docuseries’ UI/UX volume into a public, qualitative view-model contract.

## Built

- contact summaries that communicate history, reliability, obligation, and availability without exact relationship values;
- pressure cues that communicate direction, cause, and uncertainty without hidden confidence formulas;
- explicit calendar/life-course, organization assignment, property, learned-map, and notification surfaces;
- required public scope with private fields and server-only numbers omitted by construction;
- fail-soft qualitative notification tones and validation for invalid scope/bands.

## Acceptance evidence

`npm test` includes `ui-projection.test.mjs`, which proves qualitative contact and pressure language, learned-map filtering, organization assignment clarity, private-scope rejection, and stable notifications.

## Boundary

This is a headless UI view-model contract. It does not prove visual usability with fresh players, localization, controller navigation, accessibility audit, authored dialogue/audio, or a shipping native client.
