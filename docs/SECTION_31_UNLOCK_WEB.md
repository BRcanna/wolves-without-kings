# Section 31 — Needs and unlock web

This episode composes docuseries Volume 6 into an executable, persistence-tested progression web.

## Built

- unlock nodes require combinations of meaningful practice, knowledge, familiarity, elapsed time, relationships, and context;
- evaluation returns explainable unmet reasons instead of a binary mystery flag;
- the same node can become eligible through different evidence sources and histories;
- claiming a node stores explicit effects and ownership without introducing an XP currency;
- hidden/discovered visibility and public projection expose only qualitative status and unmet-count while omitting exact evidence, sources, effects, revocation rules, and event history;
- hash-linked snapshots and stale, invalid, and ineligible fail-closed writes preserve the progression history.

## Acceptance evidence

`npm test` includes `unlock-web.test.mjs`, which proves multi-dimensional gating, two distinct eligibility histories, no-XP progression, explainable lock reasons, and snapshot integrity.

## Boundary

This is a fictional progression/evidence model. It does not grant real-world credentials, teach operational procedure, or expose private competence merely because a node is evaluated.
